# SPEC — Code Generation Mapping

`generate(graph: WorkflowGraph): GeneratedFile[]` in `packages/core/src/codegen/`.
Deterministic output (stable statement order, sorted schema keys, trailing newline) so snapshot
tests and VS Code diffs are clean.

Pipeline order (unchanged from prior milestones): `validateGraph → exportGate → emit → self-lint →
sortFiles`. `generate()` refuses to emit on blocking diagnostics (`ExportGateError`) and throws
`SelfLintError` if any emitted artifact is malformed.

## Output layout

```
.claude/workflows/<slug>.js     # the dynamic-workflow orchestration script
<slug>.clauflow.json            # the saved graph (round-trip source of truth)
```

## Workflow script mapping

The graph (a DAG rooted at `workflow.meta`) linearizes to a JS module:

```js
// Generated by claude-flow-designer. Do not edit by hand.
export const meta = { name: '<meta.name>', description: '<meta.description>' }

<ordered const/await statements, if/else, while loops>

return <expr>
```

### Linearization

1. `root` = the unique `workflow.meta` node (CF601).
2. Build adjacency from `edges`. `findCycle(graph)` over all kinds → any cycle is CF603.
3. **Stable topological sort** (Kahn's): among in-degree-0 nodes, pop the one whose incoming edge
   appears earliest in `graph.edges`, else lowest `node.id`. (Mirrors `model.ts` `orderedSuccessors`.)
4. Walk the order, emitting per kind (below).

### Per-kind emission

| kind | emission |
|---|---|
| `workflow.meta` | `export const meta = { name, description }` (header; not a statement in the body) |
| `agent` | `const <bind> = await agent(\`<prompt>\`, { schema?, label?, model? })` |
| `pipeline` | `const <bind> = await pipeline(<sourceExpr>, item => agent(\`<itemPrompt>\`, { label?, schema?, model? }))` |
| `branch` | `if (<cond>) { <then-arm, topo order> } else { <else-arm> }`; `<cond>` = `<sourceBind>.<field>` (or `!…` if `negate`) |
| `loopUntilCheck` | a bounded `while` (see below) |
| `output.return` | `return <expr>;` — the last statement; exactly one |

- `<sourceExpr>` for a pipeline: `<sourceBind>.<sourceField>` when the source is a schema-producing
  node, or `args` when `source` is the meta/args.
- `<expr>` for return: `<sourceBind>` then optional `.<field>`, then optional `.filter(Boolean)`
  (`filterBoolean`) or `.flat()` (`flatten`).
- **Binding names** (`bindingName`): camelCase(`label` || `data.name` || `kind`) → sanitize to a
  valid JS identifier → append `_<topoIndex>` on collision. Pure and deterministic.

### loopUntilCheck → while

```js
let round = 0
let lastProgress = null
let <bind>
while (round < <maxRounds>) {
  const check = await agent(`<checkPrompt>`, { schema: <checkSchema>, label: 'check', model: <checkModel> })
  <bind> = check
  if (check.<passField>) break
  if (round > 0 && check.progress === lastProgress) break   // "two rounds make no progress"
  lastProgress = check.progress
  await agent(`<fixPrompt, {{check}} → check>`, { label: 'fix', model: <fixModel> })
  round++
}
```

Encodes the doc's exact termination ("until the checker passes or two rounds make no progress").
`{{check}}` in `fixPrompt` interpolates the checker result (a whole-object ref is
`JSON.stringify`-wrapped; a `.field` ref is bare).

### Template-ref substitution

`{{nodeId}}` / `{{nodeId.field}}` / `{{args}}` / `{{item}}` / `{{check}}` → JS `${…}`
interpolations against binding names. Backticks and `${` occurring literally in a user prompt are
escaped (`` \` ``, `\${`) so a hostile prompt can't break the emitted template literal. A ref to a
nonexistent / not-upstream / no-binding node is CF605 (blocked before emit).

### Determinism

- Statement order = the stable topo sort. No `Date`/RNG/map-order dependence.
- Embedded JSON-Schemas via `stableJson` (recursive key-sort) — `schema:` objects diff minimally.
- Fixed 2-space indent; single trailing newline.
- Binding names derived deterministically; template gallery fixtures regenerated + drift-checked in CI.

## Self-lint (`codegen/self-lint.ts`)

Runs inside `generate()` after emit; a failure is a codegen BUG (throws `SelfLintError`, never
silently emits). Path-containment (`isSafePath`) is checked first for every file. Per type:

- `.json` (the sidecar): `JSON.parse` succeeds; trailing newline.
- `.js` (the workflow): **real parse via `acorn`** (`ecmaVersion:'latest', sourceType:'module',
  allowAwaitOutsideFunction:true`); `export const meta` present with a string `name`; exactly one
  top-level `return` and it is the last statement; every referenced identifier resolves against
  declared `const`/`let` bindings ∪ the globals allowlist `{ agent, pipeline, args, meta, console }`;
  trailing newline.

## Importer (round-trip)

`parseProject(files) → WorkflowGraph | null`: read the `<slug>.clauflow.json` sidecar and
`parseGraphJson` it (the authoritative round-trip path). Returns `null` when no sidecar is present.
The emitted `.js` is one-way — codegen does NOT reconstruct a graph from JavaScript.
